Настройка входа в админку

Делается один раз разработчиком. Ключ GitHub зашифруется логином и паролем, и владелец будет входить только по ним.

Как получить ключ GitHub
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → severny-alyans.
  3. Permissions → Contents: Read and write.
  4. Срок действия — например, 1 год. Скопируйте ключ и вставьте ниже.

Готово ✓

Вход настроен. Через 1–2 минуты логин и пароль заработают на сайте.
